A mobile app that allows the user to search the map for food vendors that accept crypto as payment, then order and pay with crypto from connected wallet.

cryptoEATS allows the user to search for food nearby or within any area on the map, with a toggle for delivery, takeout, or dine-in. User then connects with the vendor and places an order, with payment made using crypto from a connected wallet.
