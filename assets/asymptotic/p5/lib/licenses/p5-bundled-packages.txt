Licenses and notices for the code compiled into the p5.js files

The p5.js files in assets/asymptotic/p5/lib/ (p5-1.1.9.min.js,
p5-1.4.0.min.js, p5-1.11.7.min.js and p5-1.11.11.min.js) contain code that
p5.js's own build compiles into them from the packages in part 1, and code
in p5.js's own source that carries the notices in part 2. The build removes
comments, and with them most of the license notices in that code; this file
reproduces the notices it removes. core-js's copyright, a string in its
code, stays in the files from 1.4.0 on.

Part 1 gives each package's license text where the package publishes one,
copied from the package's own published copy in
assets/asymptotic/p5/lib/source/bundled/, which holds the package as
published on npm. Where the files p5.js compiles in carry notices beyond
that text, it reproduces them. Where a package publishes no license text or
no copyright line, its entry says so. For the five packages whose upstream
source is in assets/asymptotic/p5/lib/source/upstream/, the entry also says
whether that source carries a notice beyond these, and reproduces any it
carries.

Part 2 gives the notices in p5.js's own source that the build removes. The
source archives are in assets/asymptotic/p5/lib/source/.

Quoted in-file comments are re-indented. In the license texts, umd's CRLF
line ends are normalized to LF, and each text ends in one newline. The
content is otherwise verbatim.
