The tuned prototype's whole rotation depends on writing-mode: sideways-lr. WebKit only shipped it in Safari 18.4. If it is unsupported the declaration is dropped, every column collapses to a 7 px sliver, and the marquee reads as absent — which is the symptom.

Support

A — sideways-lr  (what the prototype uses)

Should read bottom-to-top, every column flush to the bottom edge.

B — vertical-rl + rotate(180deg)  (fallback)

Should look identical to A. If A is blank or scrambled and B is correct, the fallback is the fix.

C — no JavaScript at all
